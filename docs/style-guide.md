# HomeVIS 스타일 가이드

주방 월패드·태블릿에서 매일 켜 두는 **가정용 안전 대시보드**의 화면 규칙.
새로 만들지 않고, 사람들이 이미 익숙한 제품의 방식을 그대로 가져온다.

| 기준 | 가져온 것 |
| --- | --- |
| Apple Human Interface Guidelines | 시스템 색(다크·라이트 공식 값), 글자 크기 체계, 스위치·세그먼트·시트 |
| iPad **홈** 앱 | 기기 타일 — 켜지면 밝게 반전, 꺼지면 어둡게. 타일을 눌러 켜고 끄기, … 로 상세 |
| iPad **설정** 앱 | 묶음 목록(회색 제목 · 둥근 칸 · 얇은 구분선 · 아래 설명), 색 사각 아이콘, 왼쪽 목록/오른쪽 내용 |
| 아파트 **월패드** | 큰 시계, 방별 구성(주방 · 욕실), 평면도 위 현재 위치 |

---

## 1. 하지 않는 것 (AI 가 만든 것처럼 보이는 표현)

- 아이콘 뒤 동그라미·둥근 사각 배경 — 아이콘은 그대로 쓴다 (색 사각 아이콘은 목록 앞에만)
- 카드 안에 카드 — 한 겹만. 안쪽은 구분선·여백으로 나눈다
- 설명 상자("이렇게 동작해요" 류), 범례, 인사말, 문장형 상태 줄
- 같은 정보 두 번 (상단 배너에 나온 위험을 카드에서 또 문장으로)
- 그라데이션 · 유리 효과 · 장식 이모지 · 색 값 직접 쓰기(`#xxxxxx`)

설명이 꼭 필요하면 목록 아래 **작은 회색 글(footer)** 한 줄로 쓴다 (iOS 설정과 같은 자리).

---

## 2. 색 — 토큰만 쓴다

모든 색은 `src/styles/index.css` 의 토큰이고 `html[data-theme]` 에 따라 바뀐다. 라이트가 기본 (다크·시스템은 설정에서 선택).

| 토큰 | 다크 | 라이트 | 용도 |
| --- | --- | --- | --- |
| `canvas` | `#0b0b0c` | `#f2f2f7` | 화면 바탕 |
| `surface` | `#1c1c1e` | `#ffffff` | 목록 칸 · 패널 |
| `fill` | 회색 24% | 회색 12% | 회색 버튼 · 세그먼트 · 입력칸 바탕 |
| `line` | `#38383a` | `#e5e5ea` | 목록 구분선 |
| `ink` / `ink-2` / `ink-3` | `#f5f5f7` / `#aeaeb2` / `#8e8e93` | `#1d1d1f` / `#515154` / `#6e6e73` | 본문 / 보조 / 시각·단위 |
| `brand` · `brand-ink` | `#0071e3` · `#409cff` | `#0071e3` · `#0066cc` | 주 버튼 · 링크·선택 |
| `switch` | `#30d158` | `#34c759` | 켜진 스위치 |
| `ok` · `caution` · `warn` · `danger` | Apple 시스템 색 | 고대비 변형 | 상태 (각각 `*-soft` 바탕 짝) |
| `tile-on` · `tile-off` | `#f5f5f7` · `#1c1c1e` | `#ffffff` · `#e5e5ea` | 켜진 / 꺼진 기기 타일 |
| `glyph-*` | 조명 노랑 · 환기 청록 · 물 파랑 · 화구 주황 | 같음 | 켜진 타일의 아이콘 색 |
| `sym-*` | 파랑 · 초록 · 회색 · 빨강 · 주황 · 남색 | 같음 | 목록 앞 색 사각 아이콘 |

- 흰 글자는 `brand`, `danger-fill`, `sym-*` 위에만 올린다
- 색은 상태를 알릴 때만. 상태는 항상 글자와 함께 보여준다

---

## 3. 글자·모양

- 글꼴: 시스템 글꼴만 (외부 요청 없음). Mac = SF · 애플 SD 고딕 Neo, **Windows(시연 PC) = Segoe UI · 맑은 고딕**
- 화면 제목 34px 굵게 · 구역 제목 20px 굵게 · 본문 15~17px · 보조 13px
- 시계·온도처럼 큰 숫자는 **가는 글꼴**(light) + `.tabular`
- 모서리: 타일 18px · 목록 14px · 버튼 10~16px · 시트 22px
- 누르면 살짝 흐려지고 작아진다(`.press`) — iOS 기본 반응
- 어르신 모드: 루트 글자 크기만 100~130%. 여백(`--spacing: 4px`)은 px 고정이라 배치가 흔들리지 않는다

## 4. 부품 (`src/components/ui`)

| 부품 | 규칙 |
| --- | --- |
| `Tile` | 기기·상태 하나. 아이콘(위) · 이름 · 상태 한 줄(아래). `on` 밝게 / `tone` 위험·주의 바탕 / `wide` 2칸 + 큰 값(온도·카운트다운) |
| `DeviceTile` | 조명·환풍기는 눌러서 켜고 끄기 + … 상세. 인덕션·정수기는 눌러도 상세만(조회 전용). 끊긴 기기는 "응답 없음" → 상세에서 다시 연결 |
| `DeviceCard` | 홈 화면 전용 기기 카드(v2 구성): 아이콘 · 이름·공간 · 상태 · 설명, 조명·환풍기만 오른쪽 위 스위치. 동작 중 = 밝은 카드, 꺼짐·대기·끊김 = 어두운 카드 + 흐린 글자 |
| `ListGroup` · `ListRow` | 묶음 목록. 제목(작은 회색) · 줄(아이콘 · 제목 · 값 · 스위치/›) · footer |
| `SymbolIcon` | 목록 앞 색 사각 아이콘 (설정 · 권한 · 기록 · 시연 도구) |
| `Segmented` | 같은 자리에서 보기 바꾸기 (조리/기록 탭, 풍량, 기록 분류) |
| `Toggle` | 켜고 끌 수 있는 것만. 초록 · `role=switch` |
| `Sheet` | 가운데(확인·경고) / 오른쪽(상세). 휴대폰은 아래에서. 닫기는 회색 원형 X. 열리면 창 자체에 포커스 |
| `FitList` | 높이가 정해진 칸의 목록 — 온전히 들어가는 줄만 보인다 |

하나만 고르는 설정(테마·화면 모드·언어)은 세그먼트 대신 **체크 표시 목록**을 쓴다 (iOS 설정과 같음).

## 5. 화면 크기와 배치

**홈**은 v2 배치를 쓴다: 1행 집 상태(7칸) | 지금 위치(5칸, 누르면 큰 평면도 팝업), 2행 기기 카드 4개. 최근 기록은 홈에 두지 않는다.

| 이름 | 조건 | 배치 |
| --- | --- | --- |
| **wall** | 가로 1180 이상 · 세로 660 이상 | 한 화면 고정. **페이지 스크롤 없음** |
| wall + **short** | 위 조건 + 세로 760 이하 | 같은 배치, 여백만 줄임 |
| md | 가로 768 이상 | 왼쪽 메뉴 + 세로 스크롤 |
| 기본 | 그 밖 (휴대폰) | 하단 탭 막대 + 세로 스크롤 |

- Windows 노트북 배율 150%(1920×1080 → 1280×720), 125%(→ 1536×864)도 wall 배치로 들어간다
- 검증한 크기: 1280×720 · 1536×864 · 1920×1080 · 라이트 · 어르신 130% · 820×1180 · 390×844

## 6. 사용 흐름 규칙

1. 누르면 바로 반응한다 — 비동기 동작은 "확인 중…", "연결 중…", "저장 중…"
2. 실패는 그 자리에서 말한다 — "연결하지 못했어요 · 전원을 확인해 주세요"
3. 동작은 상태에 맞게만 보인다 — 끊긴 기기에 스위치 없음, 인덕션에 켜기 버튼 없음 (안전상 조회 전용)
4. 가장 급한 것 하나만 상단 배너에 — 낙상 > 과열 > 자동 차단 > 화력 저감 > 이탈 관찰 > 연결 끊김. 위험만 빨간 막대
5. 음성으로 되는 것은 버튼으로도 되고, 상태를 바꾸는 음성 명령은 확인을 받는다
6. 권한은 이유와 함께 묻는다 — 마이크의 외부 전송 가능성을 동의 창과 설정에서 모두 알린다

---

## 7. 접근성

- 터치 대상 최소 44px, 어르신 모드 핵심 버튼 56~64px
- 포커스 링은 키보드 사용 시에만
- 위험 알림은 `alertdialog` + 음성 안내(설정에서 끌 수 있음)
- 움직임 줄이기 설정을 따르면 점멸·퍼짐·음성 막대 애니메이션이 멈춘다

## 8. 코드 구조

```
features/*  (화면, 통신 코드 없음)
store/HomeStore.tsx  (상태 · 동작)
data/source/types.ts  (메시지 이름·필드)
data/source/mockSource.ts · httpSource.ts
```

화면은 스토어만 알고, 스토어는 데이터 소스 인터페이스만 안다. 백엔드가 붙으면 `httpSource.ts` 만 채운다.
